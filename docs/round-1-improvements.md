# 第一轮改进：让界面如实表达现有数据

日期：2026-09-24。基线提交：`4d0bcd9aae47ae2b51eb7277f3639d0d97875e14`。

目标：GitHub 开源、各自在本地运行，首轮支持 Windows + Chrome。按已确认的“可信统计优先，实验结论明确标注”推进。本轮是有限范围的改进，不能据此宣布项目达到企业级发布标准。

## 交付内容

1. 移除界面中的固定健康评分、超出实现依据的 AI 处方和知识图谱，以及虚构的逐条情感、缓存状态、访问次数。
2. 保存记录直接读取 `/items`，与分析状态分开。明确“去重后的已保存页面记录”的口径，提供每页 50 条和加载更多。
3. 实验分析改为明确点击后运行；新请求立即清空旧图表。区分尚未运行、运行中、空数据、样本不足、分析不可用、后处理失败、请求失败和成功快照。
4. 按后端实际 UTC 日期对齐趋势，缺失日期/指标保持空值，合法的零值保持为零。情感比例不再采用固定默认值。
5. 分类饼图与趋势使用同一次分析的有效样本，工具和购物分别保留。分类筛选只作用于实验趋势。
6. 增加快照时间、时间窗口、有效样本和行数截断提示；数量统计与选择记录使用同一次数据库读取快照。
7. 支持 API 地址环境变量、请求取消和请求进行中的重复点击保护；失败时保留上次记录数并标注可能过时。
8. 使用原生记录弹窗，支持 Escape 关闭、焦点返回及安全的 HTTP(S) 链接；检查中英文和主题切换，修复窄屏图表溢出。
9. 更新 README、前端说明与 API 契约，纠正扩展路径和后端启动方式。新增数据转换行为测试和隔离数据库的 HTTP 契约测试。

## 本轮尚未解决

- 扩展并发入队/上传时的记录丢失、失败重试、停留时间准确性。
- 页面与访问事件混用、重复访问被忽略、数据库迁移与备份。
- 分类器默认导入错误、机器学习依赖不完整、真实推理及训练可复现性。
- 旧 `/analyze/run_full` 的降级完成语义、其他旧汇总接口的统计定义。
- 模型结果的准确性、置信度、校准和代表性；5 条门槛不构成科学有效性的证明。
- 本地接口访问保护、权限最小化、采集排除规则、数据删除/保留策略。
- 开源许可证、被跟踪数据库、依赖锁定、CI、安全扫描及发布流程。
- Vue 视图进一步拆分、前端包体积优化、完整无障碍验收和游标分页。

## 下一轮建议

先修复采集可靠性：实现可恢复上传队列，保证上传期间新增的记录不会被删除；对失败保留重试，针对并发入队、断网重连和扩展重启建立回归。随后单独设计页面与访问事件模型，保留重复访问，再建设隐私控制与稳定安装环境。

这是后续建议，第一轮实现没有修改扩展采集器、数据库结构或真实浏览数据。
