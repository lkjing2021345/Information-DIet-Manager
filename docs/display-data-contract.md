# 记录与实验统计的数据契约

适用范围：本地运行的 Windows + Chrome 产品。界面沿用原科技风和右侧抽屉；本轮只修改数据、请求状态和解释文字。分类、情感与相似度仍是实验性输出，计算口径正确不代表模型预测准确。

## 记录分页

首屏请求 `GET /items?pagination=cursor&page_size=50`。后续请求使用相同 `page_size`，并携带上一页的 `next_cursor`。响应包含 `page`、`page_size`、`total`、`items`、`pagination: "cursor"`、`snapshot_at`、`has_more`、`next_cursor`。

- 同一轮的 `total` 和 `snapshot_at` 固定。新增记录的 ID 在首次读取的上界之外，不改变这轮分页；刷新或重新打开抽屉后可见。
- 每次请求的版本、总数和记录读取在同一个 SQLite 只读事务内完成。HTTP 请求之间不持有数据库事务。
- 删除、修改或全量恢复会通过事务内触发器改变版本。旧游标返回 `409`，错误码为 `items_snapshot_expired`；事务回滚不会误使游标失效。
- 游标签名仅用于防篡改，不是访问凭证；访问接口仍须独立管理密钥。服务重启会使旧签名失效，客户端需要重新读取首屏。
- 前端收到过期信号后清空旧记录、清空并中止旧分析，只重取首屏一次；请求失败有明确失败状态，不循环重试，也不将两个快照合并。
- `has_more` 是继续加载的依据；不能通过数组去重掩盖偏移分页中的漏记录。
- 未传 `pagination=cursor` 的旧客户端仍可使用页码分页。单个响应内的总数和记录一致，但旧协议不保证多次请求之间的稳定性。

数据库通过可重复执行的增量 SQL 添加版本表与触发器，不改写用户已有记录。这不替代后续完整的版本化迁移与升级回滚体系。

## 实验统计

分析窗口内的记录按照 `(ts, id)` 升序排列。`ts` 一律解释为 Unix 毫秒，日期按 UTC 归属。流水线若删除或重排记录，接口返回失败状态，不把预测错配到其他记录。

| 字段 | 分母与缺失规则 |
|---|---|
| `count` | 该 UTC 日期的记录数；缺少相似度不删除整条记录 |
| `comparison_count` | 有效的原始相邻记录对数；首条没有前驱，空文本或不可用向量不计入 |
| `repeat_ratio` | 有效相邻对中，相似度 ≥ 0.85 的比例；无有效比较时为 `null` |
| `sentiment_count` | 有效 positive / neutral / negative 标签的记录数；失败或空文本不伪装成中性 |
| 三类情感比例 | 对应标签数量 / `sentiment_count`；分母为 0 时三项均为 `null` |
| `avg_similarity`、`avg_polarity` | 各自有效、有限且范围合法的数值均值；无有效数值时为 `null` |
| `category_counts` | 有效类别对应的记录数；不受缺失比较或情感影响 |
| `coverage` | 披露原始记录及有效时间、分类、情感、相邻比较数量，不将部分成功当作完整覆盖 |

例如五条相同文本，只有四对相邻比较；四对均达到阈值时为 100%，不是 80%。真正的相似度 0 仍参与分母。非有限值与明显越界值不能被裁剪成有效观测。

相邻关系先在整个分析窗口计算，再按后一个记录的 UTC 日期或类别归属。跨日期、跨类别的比较仍保留；选择某类别不会重算“同类别内相邻关系”。无前驱、无数据和分析失败均不画成 0。

统计缓存包含指标版本、解析后的实际起止时间、数据版本及记录 ID 上界。时间窗口前移、同毫秒内新增数据、删除或恢复均不能误用旧语义或旧数据缓存。旧评分接口不适用本契约，首页不调用这些接口。

仪表盘计算期间释放数据操作锁和数据库写锁，仅持有模型单任务锁。建任务和发布结果分别在写事务中核对数据版本；期间发生删除/恢复会返回 `409 analysis_snapshot_expired`，不会复活已删除的派生结果。直接外部更新导致任务仍存在时，旧任务标为失败。旧 `run_full` 与仪表盘共用模型锁，但仍需数据操作锁；请求槽与等待上限仍可能产生可重试的 503。

## 验证边界

API/SQLite 与前端浏览器验证使用临时数据库和合成记录。指标回归以可控预测、向量和后端桩验证边界，不下载或执行真实模型。真实模型的预测质量、词典兼容性、性能及训练可重复性需要独立验收。

本契约对应的自动回归位于 `src/hyh/tests/test_item_pagination.py`、`src/hyh/tests/test_dashboard_visualization.py`、指标测试以及 `frontend/tests/`。本轮结果与剩余门槛见 [本轮报告](security-display-2026-10-03.md)。
