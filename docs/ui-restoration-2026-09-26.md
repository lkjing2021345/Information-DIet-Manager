# 原科技风界面恢复与接口整合

日期：2026-09-26。工作起点：`d9eb3ed148f8b4b3d3cf2b302deaa29698991b11`。
视觉基线：`4d0bcd9aae47ae2b51eb7277f3639d0d97875e14`，该版本同时包含科技风首页和右侧滑出抽屉。

## 修正范围

此前第一轮修复同时替换了页面布局与抽屉样式，超出了接口和数据问题的必要修改范围。本轮恢复原设计。用户明确确认：新增的管理密钥连接、备份、恢复及删除收进原设置面板，首页保持原布局。该约束已写入根 `AGENTS.md`。

- 恢复青紫渐变标题、玻璃卡片、呼吸提示、加载动效、霓虹图表及原来的四图位置。
- 恢复右侧固定抽屉、遮罩、侧滑动画与时间线；原设置继续支持中英文、深浅主题、高亮色、四种字体。
- 所有新增管理入口放在右上角齿轮面板，包含从已加载记录中选择 ID 后删除单条记录；抽屉不增加删除按钮。
- 保留内存管理密钥、角色检查、断开/401 清空、在途响应失效、确认删除、事务恢复等现有接口行为。
- 保留真实数据含义：缺失值为空，0% 是有效值；七分类独立；图表来自同一次快照。结构图只表示本次分类计数或日期比例，明确标注为统计示意。
- 不恢复没有验证依据的健康评分、AI 处方、逐条情绪、重复访问次数和缓存状态。标题、解释文字随真实接口能力调整，不能将本轮理解为逐字逐像素回退。

后端与扩展实现没有修改；没有修改数据库、个人浏览资料或模型文件。

## 自我复查修正

1. 设置里选择第二页记录时，后台每 30 秒刷新原本会替换回第一页，导致待删除 ID 从选项中消失。现在设置/抽屉打开期间暂停轮询；此前已经发出的后台响应也不能覆盖正在操作的列表。主动刷新后会清除已失效的选择。
2. 普通卡片的 hover 上移动画会覆盖抽屉的侧滑退出动画。现在仅对普通卡片应用该 hover 变换，抽屉沿用原 slide 动画。
3. 在 `[100, null, 0]` 等稀疏情感数据中，原隐藏曲线标记的设置会让两个孤立观测都不可见。现在只为孤立情感观测显示小标记，连续曲线仍沿用原样式；缺口仍不连线。
4. 抽屉加入 Escape、焦点约束、关闭后焦点返回与背景滚动锁；长标签允许折行。设置面板可滚动，避免新增接口控件不可达。

## 仍未达到的标准

本轮是恢复设计并防止功能回退，不能据此声称所有环节无 bug，或已经满足顶级企业发布标准。当前仍有以下明确限制：

- 外观保护覆盖源码约束、浏览器几何与人工截图检查，不等同于跨浏览器、字体、缩放和设备的像素一致性保证；完整读屏验收也未完成。
- 真实模型训练/推理、质量与偏差评估仍未验收，图表必须保留实验性质。
- 原有 Vite beta 工具链、大体积图表依赖仍待单独处理；Python 测试保留一项 Starlette/httpx TestClient 弃用提示。
- 本轮 CI 的依赖安装报告 4 个受影响包；使用 `npm audit --registry=https://registry.npmjs.org` 复核同样为 3 个 high、1 个 moderate，涉及 `nanoid`、`picomatch`、`postcss`、`echarts`。这是依赖告警，不是四个已证实可利用的产品漏洞；仍需逐项评估、升级和兼容性验收，不能宣称安全扫描通过。默认 npm 镜像不提供 audit 接口，404 不代表没有漏洞。
- 当前树仍跟踪旧 SQLite 和根目录 `node_modules`，缺根许可证；发布内容清理、授权、依赖锁定、SBOM、签名发行与强制评审仍需独立完成。
- 长期运行、磁盘故障、容量边界和恢复演练仍不足，不能把合成测试等同于实际故障环境验收。

本轮的工程收益是把“保留用户设计”写成明确协作规则和可执行检查，同时将图表映射与接口生命周期分开维护。后续质量工作继续遵守这一外观边界。
