## 已完成

| 确认的问题 | 修复后的行为 |
|---|---|
| OFFSET 分页间新增/删除会漏记录，去重又掩盖遗漏 | 有签名的固定范围游标、事务版本与首屏时间；新增不挤乱分页，删除/恢复使旧游标失效 |
| 分页过期后可能混合新旧数据，晚到分析可能重新填图 | 清空旧快照、取消旧分析、请求代次隔离；只重取首屏一次，失败明确展示 |
| 首条无前驱被当作相似度 0，压低分母 | 五条同文按四个有效相邻对计算 100%；首条仍计入分类与情感 |
| 空文本、零向量和情感预测失败被伪造为有效 0/中性 | 独立有效性标记与分母；缺失为 null，有限合法零值保留；无有效情感时不生成默认比例 |
| 旧评分预处理整行删除，连带丢掉有效类别/情感 | 新建独立展示聚合模块，逐指标筛选；披露各项覆盖数量，强制核对记录 ID/时间戳对齐 |
| 时间单位猜测、窗口移动和同毫秒写入会混用缓存 | Unix 毫秒统一按 UTC 解释；缓存加入实际窗口、指标版本、数据版本及 ID 上界 |
| 长实验分析持有操作总锁，采集等请求两秒后 503 | 仪表盘模型计算不持有操作总锁或数据库写锁；真实推理入口共享模型锁 |
| 拆锁后必须防止删除/恢复后的旧分析回写 | 建任务和发布各做一次写事务内版本核对；过期返回 409，不重建已删除派生结果，外部更新遗留任务标失败 |
| 新缺失语义使旧完整样本评分不满足条件 | 旧评分验证失败返回 422/失败任务，不填造分数，也不因该输入条件返回 500 |
| 前端四个依赖包命中公告，且使用 Vite beta | 升级稳定依赖、官方 registry 锁文件；增加 npm 与最小 Python 完整树审计门禁 |

原 `App.vue` 样式块与批次前逐字对比一致（统一换行后）；`cyber-charts.js` 无差异。只修改请求、数据显示和原状态文字，未修改主题、动效、四图布局或右侧抽屉结构。人工查看深色有数据页面、浅色首页和抽屉截图；这不是跨设备像素或完整无障碍认证。
